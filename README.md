# 一小时 · ONE HOUR

每天一小时的 8 周训练计划与记录网页：周一上肢 A、周二下肢 A、周三低强度有氧与控制、周四上肢 B、周五下肢 B，周末恢复。

## 使用

- 查看四天力量、一天低强度练习与周末恢复安排。
- 展开动作，逐组输入重量、实际次数或时长并打卡。
- 切换周次，查看历史记录，记录当天感受。
- 使用 60 / 90 / 120 秒休息计时器。
- 在「我的记录」中导出或导入 JSON 备份。导入同一天的记录时保留本机已有内容。

记录保存在当前浏览器的 localStorage，不上传服务器，也不会跨设备自动同步。清理浏览器数据前请导出备份。

## 本地运行

这是无构建依赖的静态网页，HTML、CSS、JavaScript 可直接修改。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173 。

- `index.html`：页面结构。
- `style.css`：响应式布局与视觉。
- `plan.js`：每周原始训练计划。
- `app.js`：日期切换、训练记录、计时和备份。
- `icon.svg`：站点图标。

字体使用 Google Fonts，可用性受网络影响；无法加载时使用系统字体，不影响功能。

## 数据备份格式

导出文件包含 `version: 3`、按本地日期存储的 `journal` 与每周偏好 `planChoices`。导入时验证日期、动作组数与字段类型；不接受任意脚本或 HTML。训练备注显示时转义，历史记录保留原输入文本。

## 完整数据集动作库

公开动作库的原始 1,324 条数据来自 [RoiSoleil520/exercises-dataset](https://github.com/RoiSoleil520/exercises-dataset)，Fork 自 hasaneyldrm/exercises-dataset。当前固定版本 `7455efae41b330c265e7cd4b78dfa848e7ce5ebd`，共 **1,324 个独立动作**，没有以旧版 38 个动作凑数。

- 10 个部位类别、28 类器械、19 类目标肌群；支持组合筛选、按编号/英文名/中文步骤/器械/肌群搜索。
- 每页 48 个动作，共 28 页，可直接选择任意页。详情返回时保留筛选和页码。
- 原库每个动作使用原始缩略图、180×180 GIF、中文和英文完整步骤、主要及协同肌群。英文名保留原始数据，仅常用动作添加中文显示名。
- 图像懒加载；CDN 失败后尝试同一固定版本的 GitHub 原文件，详情始终提供原图链接。
- 旧版默认动作曾映射到数据集条目。其对应关系例如面拉位置使用站姿绳索后三角划船、臀推位置使用凳上双腿臀桥、Y 举使用上斜凳哑铃 Y 举、Pallof 使用弹力带版本，平板使用负重前平板条目。
- 数据库不提供训练处方，更换动作后保留原训练位置的组数与目标次数/时长，实际完成情况由用户记录。
- 更换默认仅影响选中日期。勾选「以后同一训练日也使用」后影响尚未开始的训练。
- 已保存的旧版动作记录仍绑定原动作，不改名、不把旧重量移到数据集变式。原 38 条内容仅用于历史兼容，不进入公开动作库；新动作从空白组开始。更换页面可切回本位置保留的动作记录。
- 本地记录与备份格式为 v3，继续兼容 v1/v2。

### 维护数据

- `dataset.js`：生成的 1,324 条原始字段及中英步骤，随站点加载，筛选不依赖远程 API。
- `library.js`：中文类别、器械、肌群标签和原计划映射；过滤与分页逻辑。
- `legacy-data.js`：旧版记录兼容数据，不用于新训练默认动作。
- `illustrations.js`：数据集图片/GIF 和旧记录示意图。
- `library-ui.js`：手机详情、分类/筛选/分页、动作替换。

更新数据：先在数据集 Fork 同步上游，再克隆/拉取到本地，然后在本站根目录运行：

```sh
node scripts/import-dataset.cjs /path/to/exercises-dataset
node verify.cjs
```

导入脚本验证数量和中英步骤，固定源提交 SHA；数量变化时要求人工核对。导入脚本和中文显示名均不修改上游动作步骤。

## 8 周计划更新

保留 1,324 个原库条目，增加 8 个独立补充动作（共 1,332 个）：中立握哑铃地板卧推、前臂滑墙、墙面俯卧撑加肩胛前伸、体侧弹力带外旋、坐姿短足、扶支撑单脚站立、臀推、平地走路。补充动作使用原创 SVG 与中文要领，不把近似数据集 GIF 冒充为精确示范；`supplemental.js` 保存文字与参考链接，`supplemental-art.js` 保存示意图。小红书检索仅辅助动作理解，所附笔记已标注作者声明的 AI 内容，不作为诊断依据。

- `plan.js` 保留旧计划定义，并给新版各动作指定稳定 ID、组数、次数/秒/分钟、休息时长、计划内二选一动作和提示。
- 新记录带 `planVersion: balanced-8-week-v1`，旧版无版本号记录按旧计划校验和显示，避免改变历史动作、顺序和组数。
- 有旧记录的日期默认仍展示原计划；点击「从新版计划开始这一天」先归档旧记录，再创建新版空白组。如果归档保存失败，不切换计划。归档可在历史记录中展开查看，也包含在导出备份里。
- 逐动作记录最后一组 RIR；更换动作同时保存并恢复原有组记录与 RIR。每天可记录肩部、膝部与次日反应。
- 周期起始日只在浏览器保存；显示第 1–2、3–6、7–8 周不同提示，不自动加重量或篡改历史记录。
- 新的每周动作偏好单独使用 `one-hour-plan-choices-v2`，旧偏好不会套到新计划的不同位置。
- v3 备份包含 `journal`、`planChoices`、`archivedSessions`、`programStart`；v1/v2 备份仍可导入。同日期冲突保留本机记录，旧版偏好不覆盖新版安排。
- 页面仅发布训练安排和通用提示；身体数据、具体病史、浏览器里的训练记录不会写入仓库或上传。
