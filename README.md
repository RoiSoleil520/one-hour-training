# 一小时 · ONE HOUR

每天一小时、每周五练的个人训练计划与记录网页。原始动作与组数来自用户提供的训练计划。

## 使用

- 查看周一至周五的原训练动作，周末主动恢复。
- 展开动作，逐组输入重量、实际次数或时长并打卡。
- 切换周次，查看历史记录，记录当天感受。
- 使用 60 / 90 / 120 秒休息计时器。
- 在「我的记录」中导出或导入 JSON 备份。导入同一天的记录时保留本机已有内容。

记录保存在当前浏览器的 localStorage，不上传服务器，也不会跨设备自动同步。清理浏览器数据前请导出备份。

## 本地运行

这是无构建依赖的静态网页，HTML、CSS、JavaScript 可直接修改。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173 。

- `index.html`：页面结构。
- `style.css`：响应式布局与视觉。
- `plan.js`：每周原始训练计划。
- `app.js`：日期切换、训练记录、计时和备份。
- `icon.svg`：站点图标。

字体使用 Google Fonts，可用性受网络影响；无法加载时使用系统字体，不影响功能。

## 数据备份格式

导出文件包含 `version: 2`、按本地日期存储的 `journal` 与每周偏好 `planChoices`。导入时验证日期、动作组数与字段类型；不接受任意脚本或 HTML。训练备注显示时转义，历史记录保留原输入文本。

## 动作库与动作替换

新版包含 38 个动作，按背部、胸部、肩部、二头、三头、臀部、腿部、核心、全身分类，支持按动作名、肌群、器械搜索。

- 展开训练动作，点击示意图或「动作要领」查看起始/发力姿势、准备姿势、3 条要领和常见错误。
- 点击「更换动作」，从动作库选择替代项。保留原位置的组数，次数/时长采用新动作的参考目标。
- 默认只影响选中日期；勾选「以后同一训练日也使用」后，尚未开始的同一训练日会使用该选择。
- 旧动作的重量、次数和打卡状态按日期与动作保留，换回时可继续；新动作不会继承旧动作的重量。
- 既有训练记录保留当时的动作，不会随每周偏好改名。
- 备份升级为 `version: 2`，包含每周偏好与替换前的动作记录；仍支持导入第一版备份。同日期记录、同训练日偏好冲突时保留本机内容。

相关源码：

- `library.js`：动作内容。新增动作时填写稳定的 `id`、名称、部位、器械、参考次数、准备姿势、要领、常见错误、示意图类型与资料链接。
- `illustrations.js`：原创 SVG 位置示意，随网页加载，无外部图片依赖。相同动作模式可复用示意类型，不同器械/握法由文字说明补充；新增动作模式须增加对应的关键姿势。
- `library-ui.js`：分类、搜索、手机说明弹层、动作替换入口。

动作说明为中文整理，详情页附 ACE / NASM 的公开动作指南或动作库参考链接。图示展示关键位置与方向，活动范围以能控制且舒适为准。

## 回归验证

使用 Node.js 16 或更新版本，在仓库根目录运行：

```sh
node verify.cjs
```

检查动作覆盖、全部示意图生成、旧记录兼容、更换/切回记录恢复、每周偏好和无效备份数据拦截。
